# Catálogo, criação e execução de agentes no VS Code

## Escopo e entradas

`vscode-extension/` é um pacote de extensão VS Code com entrada em `src/extension.js`, ativado pela vista `agentOrchestra.files` e executado no host de workspace. Seus subarquivos são camadas técnicas da extensão, não módulos de negócio independentes ([`package.json:10`](../../../vscode-extension/package.json#L10), [`package.json:26`](../../../vscode-extension/package.json#L26), [`extension.js:25`](../../../vscode-extension/src/extension.js#L25)). A capacidade funcional confirmada aqui é organizar artefatos de agentes e iniciar tarefas com eles. A Forja que produz os artefatos é descrita em [Geração de agentes](agent-generation.md); mapa e notas de projeto, em [Documentação do projeto](project-documentation.md). Monitoramento, painel, scripts, compartilhamento e atualização estão em [Integrações da extensão](extension-integrations.md).

O catálogo aceita pastas locais abertas no VS Code e, se `agentOrchestra.includeUserInstallations` estiver ligado, a instalação do usuário. Procura agentes Codex em `.codex/agents/*.toml`, agentes Claude em `.claude/agents/*.md`, skills em `.agents`, `.codex` e `.claude`, rotas da Forja, especificações e instruções na raiz. Para cada skill, descobre `SKILL.md` e scripts com extensões admitidas; acrescenta um analisador de diff e roteiros integrados para workspaces ([`catalog.js:6`](../../../vscode-extension/src/catalog.js#L6), [`catalog.js:32`](../../../vscode-extension/src/catalog.js#L32), [`catalog.js:65`](../../../vscode-extension/src/catalog.js#L65), [`extension.js:35`](../../../vscode-extension/src/extension.js#L35)). A árvore separa raiz, grupo e arquivo; expõe prévia Markdown, busca, abertura e ações conforme a categoria. O clique em script abre suas instruções; o clique em roteiro inicia a seleção do agente ([`extension.js:47`](../../../vscode-extension/src/extension.js#L47), [`extension.js:68`](../../../vscode-extension/src/extension.js#L68), [`extension.js:93`](../../../vscode-extension/src/extension.js#L93), [`extension.js:121`](../../../vscode-extension/src/extension.js#L121)).

## Criação

O comando manual pede projeto, tipo e nome e oferece modelos para agente Claude, agente Codex ou skill compartilhada. `createFile` valida o nome, recusa links simbólicos no caminho e grava com `wx`, portanto um arquivo existente bloqueia a criação ([`extension.js:129`](../../../vscode-extension/src/extension.js#L129), [`catalog.js:86`](../../../vscode-extension/src/catalog.js#L86), [`catalog.js:92`](../../../vscode-extension/src/catalog.js#L92)). A criação guiada pede perfil, nome, papel e missão, chama o backend Python para produzir uma especificação JSON em `.agentorchestra/specs/` e permite revisar o arquivo antes da geração. O build da extensão oferece `unified-project` ou `claude-project` e chama o núcleo da Forja empacotado ([`extension.js:144`](../../../vscode-extension/src/extension.js#L144), [`extension.js:158`](../../../vscode-extension/src/extension.js#L158), [`forge.js:14`](../../../vscode-extension/src/forge.js#L14), [`forge.js:33`](../../../vscode-extension/src/forge.js#L33)).

## Execução

O comando `runAgent` aceita um agente da árvore ou abre uma escolha entre agentes Claude e Codex. Resolve o projeto de trabalho, um dos seis roteiros (`mission`, `diff`, `bug`, `tests`, `docs`, `security`), texto complementar e o destino terminal ou extensão oficial. Os roteiros contêm instruções iniciais, não motores de execução separados ([`extension.js:283`](../../../vscode-extension/src/extension.js#L283), [`extension.js:295`](../../../vscode-extension/src/extension.js#L295), [`agentRuns.js:6`](../../../vscode-extension/src/agentRuns.js#L6)). O nome é lido do front matter Claude ou da chave TOML Codex, com fallback para o nome do arquivo e validação antes de compor o prompt. Para Codex, a instrução pede delegação ao subagente personalizado; para Claude, pede executar como o agente selecionado. Quando existe um handoff do projeto, o prompt manda lê-lo primeiro e confirmar no código o que interessa à tarefa ([`agentRuns.js:27`](../../../vscode-extension/src/agentRuns.js#L27), [`agentRuns.js:42`](../../../vscode-extension/src/agentRuns.js#L42), [`extension.js:319`](../../../vscode-extension/src/extension.js#L319)).

No terminal, a extensão verifica o CLI configurado e cria uma `vscode.Task` com `ProcessExecution`, `cwd` no projeto e painel de terminal dedicado. Claude recebe `--agent <nome>`; Codex recebe `--cd <projeto>` e um prompt de delegação. O registro em memória acompanha início, término e código de saída pelos eventos de tarefas do VS Code; a árvore e o painel consultam esse registro ([`extension.js:276`](../../../vscode-extension/src/extension.js#L276), [`extension.js:338`](../../../vscode-extension/src/extension.js#L338), [`agentRuns.js:51`](../../../vscode-extension/src/agentRuns.js#L51), [`extension.js:230`](../../../vscode-extension/src/extension.js#L230)).

Na opção extensão oficial, a extensão verifica a presença de `anthropic.claude-code` ou `openai.chatgpt`, copia o prompt e abre o comando de conversa correspondente. O estado fica `prepared` até o usuário colar e enviar a instrução; não há confirmação de que a extensão oficial a executou ([`extension.js:327`](../../../vscode-extension/src/extension.js#L327), [`dashboard.js:55`](../../../vscode-extension/src/dashboard.js#L55)).

## Dependências e limites

Criar, gerar e executar exigem workspace confiável; os fluxos trabalham com pastas locais, APIs de árvore/tarefas do VS Code e CLIs Claude/Codex configuráveis ([`extension.js:23`](../../../vscode-extension/src/extension.js#L23), [`extension.js:129`](../../../vscode-extension/src/extension.js#L129), [`extension.js:283`](../../../vscode-extension/src/extension.js#L283), [`package.json:326`](../../../vscode-extension/package.json#L326)). A Forja, importação de ZIP e parte da análise estrutural precisam de Python 3.10+; se `pythonPath` permanece no padrão e o executável falta, o resolvedor tenta instalar Python 3.13 no armazenamento da extensão mediante download ([`python.js:31`](../../../vscode-extension/src/python.js#L31), [`python.js:82`](../../../vscode-extension/src/python.js#L82), [`python.js:121`](../../../vscode-extension/src/python.js#L121)).

**Não verificado:** execução de ponta a ponta no VS Code, disponibilidade real dos comandos das extensões oficiais, instalação automática do Python e resultado produzido por Claude/Codex. A descrição acima é uma validação estática do caminho implementado. **Inferência:** tratar catálogo e execução como uma capacidade funcional é uma classificação editorial; `catalog.js`, `agentRuns.js` e `extension.js` pertencem ao mesmo pacote técnico.
