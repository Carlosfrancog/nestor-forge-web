Como instalar ou atualizar

  1. Baixe o arquivo VSIX desta versão.
  2. No VS Code, abra Extensões com Ctrl+Shift+X.
  3. Abra o menu … e escolha Instalar do VSIX….
  4. Selecione o arquivo baixado e recarregue a janela, se solicitado.

Como funcionam as atualizações ↗

Após instalar esta versão, use AgentOrchestra: Verificar atualizações no VS Code. A extensão consulta o manifesto de atualização, avisa quando houver versão nova e permite instalar em um clique. Em configurações, selecione agentOrchestra.updateMode: auto para instalar automaticamente. Recarregue a janela quando solicitado.
